Development

Ideas made operational.

The development work is not separate from the writing. It is where an argument becomes a system someone can enter, use, question, save, combine, and return to.

Interactive web system

The Dark Hierarchy Tools

This six-part interactive system is a digital extension of the book The Dark Hierarchy: A Treatise on Authority, Initiation, and the Order. The book establishes the concepts; the tools let a reader enter that architecture through structured reflection, individual results, and comparison.

Each tool translates a defined part of the book into an experience rather than reducing the work to a summary. Together they generate readable interpretations and visual result cards, create six-character retrieval codes, and allow several results to be assembled into one profile. Two people can also compare profiles without creating accounts.

Attachment Confirmation

04 · Reflection

Dark Night Diagnostic

Helps practitioners distinguish a difficult passage from a genuine failure of the framework.

05 · Generator

Protocol Designer

Constructs a personal package of daily and weekly practices from the user’s circumstances.

06 · Reflection

Threshold Self-Assessment

Offers structured reflection when someone is considering entering, acknowledging, or leaving something.

Connected results

Each result receives a retrieval code. Codes can be revisited on another device, assembled into a layered profile, or compared between two people.

Resilient storage

Local browser storage provides immediate continuity. A remote profile service supports cross-device retrieval, with graceful local fallback.

Generated artifacts

Several tools render individual maps and result cards directly in the browser for saving and sharing.
